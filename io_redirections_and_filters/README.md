#Shell, I/O Redirections and filters\
Add file 0-hello_world to print "Hello, World" when executed.\
Add file 1-confused_smiley to print a confused smiley.\
Add file 2-hellofile to display the content of the /etc/passwd file.\
Add file 3-twofiles to display contents of /etc/passwd and /etc/hosts.\
Add file 4-lastlines to print last 10 lines of /etc/passwd.\
Add file 5-firstlines to print the first 10 lines of /etc/passwd.\
Add file 6-third_line to display the third line of the file iacta.\
Add File 7-file to create a file named exactly \*\\'"Best School"\'\\*$\?\*\*\*\*\*:) containing the text Best School ending by a new line.\
Add File 8-cwd_state to list contents of ls -la into file ls_cwd_content.\
Add file 9-duplicate_last_line to duplicate the last line of iacta file.\
Add file 10-no_more_js to find all .js files on system and remove them. This is destructive and will remove all files with .js extension.\
Add file 11-directories to list all directories and sub directories in the current working folder.\
Add file 12-newest_files to list the 10 most newest files in the current directory.\
Add file 13-unique to list words as input and prints only words that appear exactly once.\
Add file 14-findthatword to display lines containing the pattern "root" from file /etc/passwd.\
Add file 15-countthatword to display the number of lines that contain the pattern "bin" in the file /etc/passwd.\
Add file 16-whatsnext to display lines containing the pattern "root" and 3 lines after them in the file /etc/passwd.\
Add file 17-hidethisword to display all the lines in the file /etc/passwd that do not contain the pattern "bin".\
Add file 18-letteronly to display all lines of the file /etc/ssh/sshd_config starting with a letter, including capital letters.\
Add file 19-AZ, this script will replace all characters 'A' and 'c' from input to 'Z' and 'e'.\
Add file 20-hiago, this script removes all letters c and C from input.\
Add file 21-reverse to reverse input. \
