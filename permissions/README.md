#Shell Permissions README.\
Scripts in this folder will teach the user how to use permissions.\
Add file 0-iam_betty to switch user to betty user.\
Add new file 1-who_am_i to display the current user.\
Add new file 2-groups to display current users group.\
Add new file 3-new_owner to change owner of file hello to betty.\
Add new file 4-empty to create new file called hello.\
Add new file 5-execute to change hello file to have execute permissions.\
Add new file 6-multiple_permissions to repository. Changes user and groups to execute and others to read only.\
Add new file 7-everybody, which changes permissions to user, groups and others to execute.\
Add new file 8-James_Bond to set permissions for file hello to, Owner: no permission at all, Group: no permission at all, Other users: all the permissions.\
Add new file 9-John_Doe to set permissions to file hello rwxr-x-wx.\
