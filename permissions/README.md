#Shell Permissions README.\
Scripts in this folder will teach the user how to use permissions.\
Add file 0-iam_betty to switch user to betty user.\
Add new file 1-who_am_i to display the current user.\
Add new file 2-groups to display current users group.\
Add new file 3-new_owner to change owner of file hello to betty.\
Add new file 4-empty to create new file called hello.\
Add new file 5-execute to change hello file to hav execute permissions.\
